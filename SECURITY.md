# Security Policy | 安全策略

**[简体中文](#简体中文)** | **English**

## Reporting a vulnerability | 报告漏洞

**Do not open public issues for security vulnerabilities.**

Please report vulnerabilities to: **security@acssa.cn**

Include:

- Description of the issue and affected module(s)
- Reproduction steps or PoC
- Affected version / commit
- Your assessment of severity and suggested remediation, if any

We will acknowledge receipt within **7 days** and keep you informed of the fix progress. Coordinated disclosure: please hold public disclosure until a fix is released. We will credit reporters in the release notes (unless you prefer to remain anonymous).

## Scope | 范围

In scope: the open-source base modules (`qingtian/`), docker-compose deployment, and the gateway.

Out of scope: social engineering, DoS against our public services, vulnerabilities in third-party dependencies (report upstream), issues in unreleased/feature branches.

# 简体中文

**安全漏洞请勿公开提 issue**，请发送至：**security@acssa.cn**

邮件中请包含：问题描述与受影响模块、复现步骤或 PoC、受影响版本/提交号、严重性评估与修复建议（如有）。

我们将在 **7 天内**确认收到，并持续同步修复进展。请协调披露：修复发布前请勿公开。报告者将在 Release Notes 中致谢（除非希望匿名）。

**范围内**：开源底座模块（`qingtian/`）、docker-compose 部署、网关。
**范围外**：社会工程、针对我们公共服务的 DoS、第三方依赖自身的漏洞（请向上游报告）、未发布分支的问题。
