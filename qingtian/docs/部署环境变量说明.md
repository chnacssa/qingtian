# 部署环境变量说明

> 适用范围：ACSSA 智能体操作系统（底座 OS）开源发行版
> 配套：`config.yaml` / `config.yaml.example`（配置模板）

## 配置优先级

```
环境变量  >  config.local.yaml（override 深度合并）  >  config.yaml  >  代码内默认值
```

- **环境变量**：代码层 `os.environ` 直接读取，优先级最高。敏感值（密码/令牌/API Key）一律走此通道，**禁止明文写入 config.yaml**（R11 B3/B5 安全修复）。
- **config.local.yaml**：与 config.yaml 同目录，`{ override: {...} }` 深度合并到主配置之上，用于每台服务器独立的差异项（role/host/peer_id 等），rsync 部署时排除此文件。
- **config.yaml**：仓库内置占位符模板（`${ENV}` 引用的变量见下表），可直接复制为 `config.yaml` 使用。

---

## 必配变量（4 个）

| 环境变量 | 用途 | 配置位置 | 缺失影响 |
|----------|------|----------|----------|
| `DEEPSEEK_API_KEY` | DeepSeek LLM 调用（yongheng 蒸馏/摘要、common 三档路由 precise/reasoning 档、bidding 解析复核） | `yongheng.llm.api_key`、`common.llm.precise/reasoning.api_key` | LLM 功能不可用，知识蒸馏/投标解析失败 |
| `DASHSCOPE_API_KEY` | 阿里云 DashScope：embedding 向量化 + common 三档路由 simple 档 | `yongheng.embedding.dashscope.api_key`、`common.llm.simple.api_key` | 采购/销售角色 embedding 不可用，记忆检索失效 |
| `ZHENYUE_ADMIN_TOKEN` | 镇岳安全审计管理令牌（bootstrap_admin_token + OpenClaw adapter push 鉴权） | `zhenyue.auth.bootstrap_admin_token`、`gateway.adapters.openclaw.push.token` | 镇岳首次部署无法引导；OpenClaw 消息推送被拒 |
| `QINGTIAN_DB_PASSWORD` | PostgreSQL 数据库密码（B3 替代明文 `database.password`） | 代码层 `common/db.py` 读取 | DB 密码留空时部署脚本会提示设置，连接失败 |

## 可选变量（7 个）

| 环境变量 | 默认值 | 用途 |
|----------|--------|------|
| `QINGTIAN_CONFIG` | `/opt/qingtian/config.yaml` | 主配置路径（测试/多实例部署时指向其他文件） |
| `HUANYU_SIGN_KEY` | 空（校验 fail-closed → 免费） | 寰宇跨底座消息 HMAC 签名密钥，生产环境**建议必配** |
| `YONGHENG_BOOTSTRAP_TOKEN` | 部署脚本生成 | 永恒首次部署引导令牌，重启后自动生成替换 |
| `QINGTIAN_PORTAL_MAX_UPLOAD_MB` | `500` | 门户/知识库文件上传大小上限（MB），2026-08-31 起 300→500 |
| `QINGTIAN_SKILLS_DIR` | `/opt/qingtian/skills` | Skill 安装目录（import_loader 导入落点） |
| `QINGTIAN_SKILL_DATA_DIR` | `/opt/qingtian/skills/data` | Skill 共享数据目录（loader/CLI/market_integration 同源） |
| `ZHICE_DB_HOST` / `ZHICE_DB_USER` / `ZHICE_DB_NAME` | `localhost` / `qingtian` / `qingtian` | 执策（智采）独立数据库连接，默认跟随主库，分库部署时覆盖 |

## 注入方式示例

**systemd（生产推荐）**：`/etc/systemd/system/qingtian.service`

```ini
[Service]
Environment=QINGTIAN_DB_PASSWORD=xxxxxxxx
Environment=DEEPSEEK_API_KEY=sk-xxxxxxxx
Environment=DASHSCOPE_API_KEY=sk-xxxxxxxx
Environment=ZHENYUE_ADMIN_TOKEN=xxxxxxxx
Environment=HUANYU_SIGN_KEY=xxxxxxxx
```

**shell 启动**：

```bash
export QINGTIAN_DB_PASSWORD=xxxxxxxx
export DEEPSEEK_API_KEY=sk-xxxxxxxx
export DASHSCOPE_API_KEY=sk-xxxxxxxx
export ZHENYUE_ADMIN_TOKEN=xxxxxxxx
python3 main.py
```

**config.local.yaml**（每台服务器独立差异项，不进仓库）：

```yaml
override:
  role: procurement
  host: procurement-server
  host_ip: 10.0.100.2          # 内网 IP 仅写本地覆盖，不进仓库
  huanyu:
    redis_url: "redis://10.0.100.1:6379"
```

## 备注

- 新增环境变量均为**代码层直接读取**（`os.environ`），不体现在 config.yaml 结构里——配置表中"配置位置"标注为"代码层"即属此类。
- 变更记录：`QINGTIAN_DB_PASSWORD` 由 R11 B3 引入（去除明文密码）；`QINGTIAN_PORTAL_MAX_UPLOAD_MB`、`QINGTIAN_SKILLS_DIR`、`QINGTIAN_SKILL_DATA_DIR`、`ZHICE_DB_HOST/USER/NAME` 由 R11 P2 修复引入（配置化 + 分库支持）。
