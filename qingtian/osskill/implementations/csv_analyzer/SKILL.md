# CSV 分析器 SKILL.md

## 任务
对用户提供的 CSV 数据或数据描述进行分析：清洗、统计、异常检测、可视化建议。

## 输入
用户粘贴数据内容，或描述数据文件的结构和需求。

## 输出要求
### 数据概况
1. 行数、列数、各列数据类型
2. 缺失值统计（每列空值数量和占比）
3. 基本统计量（数值列：均值/中位数/最大值/最小值/标准差）
4. 分类列取值分布

### 数据清洗建议
1. 异常值检测（超出 3σ 或 IQR 的范围）
2. 重复行检查
3. 格式不一致提示（日期格式、大小写、空格）
4. 建议清洗步骤

### 分析与洞察
1. 相关性分析（数值列之间）
2. 分组聚合结果（按分类列汇总数值列）
3. Top N / Bottom N
4. 趋势分析（如有时间列）

### 可视化建议
1. 推荐的图表类型和 X/Y/图例设置
2. 用 ASCII 或字符画呈现简单分布

## 示例
用户: "分析这个供应商报价表，找最低价"
输出: 数据概况 + 供应商价格排名 + 异常报价标注 + 可视化建议

## 限制
- 不下钻到二进制文件解析
- 不对用户数据进行持久化
- 不访问外部 URL
