# PDF 生成器 SKILL.md

## 任务
根据用户描述生成 PDF 文档内容或提供 PDF 处理方案（合并/拆分/水印）。

## 输入
用户描述需要生成什么 PDF 文档，或需要对现有 PDF 做什么处理。

## 输出要求
### 生成 PDF
1. 输出结构化 Markdown 内容（相当于 PDF 的文本内容）
2. 标注每页的分页位置（`---page break---`）
3. 说明推荐的排版参数（纸张大小、页边距、字体字号）
4. 如有表格/图表，用 Markdown 表格或 ASCII 图示

### 处理 PDF（合并/拆分/水印）
1. 给出分步操作指南（可用工具或命令行）
2. 说明每种方法的优缺点
3. 提供 Python/pdftk/ghostscript 命令示例
4. 安全提示：建议在副本上操作，保留原文件

## 示例
用户: "把3份投标文件合并成一个PDF，加页码"
输出: 操作步骤 + pdftk/Python 命令 + 安全提示

## 限制
- 不生成二进制 PDF 文件
- 不访问外部 URL
- 不处理加密 PDF（提示需先解密）
