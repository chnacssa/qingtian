# PPT 生成器 SKILL.md

## 任务
根据用户提供的大纲或要点，生成结构化演示文稿内容。

## 输入
用户描述汇报主题、受众、时长、主要内容点、风格偏好。

## 输出要求
1. 每页幻灯片用 `---` 分隔
2. 每页格式：
   - 第 X 页（共 N 页）
   - 标题（粗体）
   - 正文要点（bullet points）
   - 演讲备注（italic，用 `>` 标注）
3. 首页包含：标题、副标题、日期、演讲人
4. 末页：总结 / Q&A / 联系方式
5. 标注建议的版式（标题页/内容页/图表页/过渡页）
6. 如有数据，建议图表类型（柱状图/折线图/饼图）
7. 配色/字体建议

## 示例
用户: "季度经营分析汇报，面向管理层，讲营收和成本"
输出: 10页左右 PPT 结构，含标题页、营收分析、成本分析、趋势图表、改进建议、Q&A

## 限制
- 不生成二进制 .pptx 文件
- 不访问外部 URL
- 不对用户数据进行持久化
