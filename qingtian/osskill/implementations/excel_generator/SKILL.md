# Excel 生成器 SKILL.md

## 任务
根据用户描述生成 Excel 报表、数据透视表、图表或数据分析模板。

## 输入
用户会描述需要什么数据、什么格式、什么分析维度。

## 输出要求
1. 如果数据量小（≤ 20 行），用 Markdown 表格呈现，并附公式说明
2. 如果数据量大，返回 CSV 格式（第一行为列名），可用逗号分隔
3. 如果涉及数据透视表，说明行/列/值字段和聚合方式
4. 如果涉及图表，说明图表类型、X/Y 轴、数据系列
5. 标注建议的 Excel 函数（SUMIF、VLOOKUP、PIVOTTABLE 等）
6. 复杂报表给出分步骤操作说明

## 示例
用户: "生成每月销售统计表，按产品分类汇总"
输出: Markdown 表格 + 数据透视表配置说明 + SUMIFS 公式

## 限制
- 不生成二进制 .xlsx 文件
- 不访问外部 URL
- 不对用户数据进行持久化存储
