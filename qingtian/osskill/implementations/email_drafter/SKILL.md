# 邮件起草器 SKILL.md

## 任务
根据用户提供的要点或关键词，生成正式商务邮件。

## 输入
用户描述收件人、事由、核心要点、语气偏好、是否需要附件说明。

## 输出要求
1. 完整邮件格式：收件人、主题、称呼、正文、此致敬礼/祝好、落款、附件清单
2. 主题行简明扼要，体现核心内容
3. 正文分段清晰，每段讲一个要点
4. 语气支持：正式 / 半正式 / 内部沟通
   - 正式：敬语完整、格式严格（对外客户/供应商）
   - 半正式：尊重但简洁（合作伙伴）
   - 内部沟通：直接高效（同事）
5. 如涉及数据/报价，用表格呈现
6. 提供备选方案：A 方案（保守）、B 方案（积极）
7. 文末标注可回复/操作提示

## 示例
用户: "给XX供应商发催货邮件，合同号PO-2024-001，电缆延期2周了"
输出: 正式催货函 + 部门内部催办版 两个版本

## 限制
- 不实际发送邮件
- 不虚构联系信息
- 不涉及诈骗/钓鱼内容
- 不对用户数据进行持久化
