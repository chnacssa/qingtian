# 文件格式转换器 SKILL.md

## 任务
根据用户需求在不同文档格式之间进行内容转换。

## 支持格式
- Markdown（.md）
- HTML（.html）
- 纯文本（.txt）
- CSV 表格数据

## 输入
用户提供源内容或描述需要转换的内容和格式。

## 输出要求
1. 明确标注源格式和目标格式
2. 保持内容完整性，不丢失信息
3. 格式转换规则：
   - Markdown ↔ HTML：标题、列表、表格、链接、代码块、图片完整映射
   - Markdown ↔ 纯文本：去掉格式标记，保留段落结构
   - CSV ↔ Markdown 表格：列对齐、表头映射
   - HTML → Markdown：去掉样式标记，保留结构和链接
4. 转换后附格式差异说明（哪些元素无法完美对应）
5. 如有敏感数据（身份证号、银行卡号），标注"建议脱敏后转换"

## 示例
用户: "把这个HTML格式的标书通知转成Markdown"
输出: 干净整理的 Markdown + 格式映射说明

## 限制
- 不生成二进制文件（docx/xlsx/pdf）
- 不访问外部 URL
- 不对用户数据进行持久化
- 内容超过 8000 字时分段处理
